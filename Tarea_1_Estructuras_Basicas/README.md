## Compilación y Ejecución

Para compilar los programas en C:
```bash
gcc ejercicio1.c -o ejercicio1
./ejercicio1
```

Para compilar los programas en C++:
```bash
g++ ejercicio10.cpp -o ejercicio10
./ejercicio10
```
